# Беларускі інтэрфейс для Steam

[English](README.md) | **Беларуская**

Плагін для [Millennium](https://steambrew.app), які паказвае кліент Steam па-беларуску.

## Навошта патрэбны гэты плагін

У кліенце Steam няма беларускай мовы. Гэты плагін запаўняе прабел: ён працуе паверх той мовы,
якая абраная ў Steam, і робіць так, што радкі ўласнага інтэрфейсу кліента паказваюцца
па-беларуску. Радок без перакладу застаецца на той мове, якая абраная ў Steam.

таму плагін кліента да іх не дастае.

## Усталяванне

Уключыце «Belarusian UI» у Millennium пасля ўсталявання плагіна. Каб сабраць яго з зыходнага кода,
патрэбныя Windows, Steam з Millennium і Node.js 24 або навейшы:

```bash
npm install
npm run build      # збірае і ўсталёўвае ў папку плагінаў Millennium; перазапусціце Steam
npm run pack       # або: збірае пакет .star у build/
```

## Як працуе плагін

Сам плагін — два невялікія файлы, разам каля 110 радкоў:
[frontend/index.tsx](frontend/index.tsx) і [frontend/patch.ts](frontend/patch.ts).

Steam паказвае кожны радок інтэрфейсу праз свой `LocalizationManager`, у якім ёсць табліца
`token id → text`. Пры запуску плагін:

1. Правярае, што `window.LocalizationManager` мае чаканую будову. Калі не, піша памылку ў кансоль
   і не чапае Steam.
2. Перазапісвае значэнні ў табліцы токенаў (`m_mapTokens`) беларускімі, таму React адразу малюе
   па-беларуску. Ніякага абходу DOM, ніякіх абсёрвераў і ніякай працы на кожны кадр.
   Аб’яднанне займае каля 15 мс на прыкладна 15 000 радкоў.
3. Абгортвае `AddTokens`, каб радкі, якія Steam загружае пазней, таксама перакладаліся.
4. Дадае пераклады для радкоў, якія Steam трымае ў асобным «агульным» (shared) сховішчы і якіх
   няма ў табліцы (прыклад — меню статусу сяброў).

Пераклады — звычайныя даныя, якія кампілююцца ў плагін пры зборцы
(`frontend/generated/translations.ts`, у рэпазіторый не трапляе). Ключы — уласныя ідэнтыфікатары
токенаў Steam, якія не змяняюцца пры абнаўленнях. У некалькіх ідэнтыфікатараў у розных модулях
Steam розны ангельскі тэкст, таму плагін шукае радкі яшчэ і па іх ангельскім тэксце.

## Што яшчэ ёсць у гэтым рэпазіторыі

Усё па-за `frontend/` патрэбна для стварэння і падтрымання перакладу. Нішто з гэтага не працуе
ўнутры Steam і не ўваходзіць у плагін.

| Шлях | Што гэта |
|---|---|
| `frontend/` | **Плагін** (гл. вышэй). |
| `translations/be/` | **Даныя:** беларускі пераклад у файлах XLIFF і `source/` — ангельскія і рускія радкі Steam, на якіх ён заснаваны. |
| `tools/pipeline/` | Скрыпты, якія здабываюць радкі са Steam, ствараюць XLIFF для перакладчыкаў, пераносяць пераклад на новую версію Steam і кампілююць яго для плагіна. |
| `tools/steam-watch/` | Неабавязковая штодзённая праверка радкоў Steam з апавяшчэннем Windows. |
| `docs/screenshots/` | Здымкі экрана для гэтага README. |
| `test/` | Тэсты плагіна і інструментаў. |

Большая частка кода ў гэтым рэпазіторыі — інструменты і тэсты, а не код плагіна. Steam часта
змяняе свае радкі, і гэтыя інструменты дазваляюць аднаму чалавеку паспяваць за ім.

## Працэс перакладу

Перакладчыкі працуюць з рускіх радкоў, а ангельская, украінская і польская мовы — дапаможныя.
Пераклад ідзе ў [bellingua](https://github.com/Thrapis/bellingua) — асобным праекце, які
імпартуе і экспартуе XLIFF 1.2. Гэты рэпазіторый стварае файлы, якія імпартуе bellingua, і
збірае плагін з таго, што bellingua экспартуе.

  <img src="docs/workflow.svg" alt="Працэс перакладу: здабыць радкі Steam, стварыць XLIFF, перакласці ў bellingua, экспартаваць у translations/be, скампіляваць у плагін" width="880">

Steam шукаецца праз `--steam <dir>`, потым праз зменную асяроддзя `STEAM_DIR`, потым праз
рэестр. Каманда `npm run compile -- --min-state translated|approved` уключае ў плагін толькі
правераныя радкі; па змаўчанні (`mt`) уключаюцца і машынныя пераклады.

## Інструменты

### Абнаўленне да новай версіі Steam

```bash
npm run update-strings
```

Гэта здабывае бягучыя радкі Steam, нанова стварае дрэвы XLIFF і пераносіць пераклад:

- Пераклады нязмененых радкоў застаюцца як ёсць.
- Чалавечыя пераклады захоўваюцца, нават калі змяніўся рускі тэкст, але атрымліваюць стан
  «translated» і заўвагу са старым рускім тэкстам. Машынныя пераклады радкоў, якія змяніліся,
  выдаляюцца.
- Калі змяніўся толькі ангельскі тэкст, пераклад застаецца з заўвагай са старым і новым
  ангельскім тэкстам.
- Пераклад, у якім не супадаюць плэйсхолдары, выдаляецца, а яго тэкст
  застаецца ў заўвазе.
- Папярэдняе дрэва пераназываецца ў `translations/be.old-<date>` і ніколі не выдаляецца.
  Git яго ігнаруе.

Потым імпартуйце `translations/be` і дрэвы `l10n/reference-*` у bellingua, перакладзіце,
экспартуйце назад у `translations/be` і запусціце `npm run build`.

### Штодзённая праверка (неабавязкова)

`npm run check` параўноўвае бягучыя радкі Steam з тымі, на якіх заснаваны `translations/be`, і
паказвае апавяшчэнне Windows, калі яны адрозніваюцца. Націск на апавяшчэнне адкрывае справаздачу.
Праверка маўчыць, калі нічога не змянілася або калі пра гэтую змену ўжо паведамлялася.

```bash
npm run schedule -- install            # штодня ў 12:00
npm run schedule -- install --at 09:30
npm run schedule -- status
npm run schedule -- uninstall
```

Задача працуе ад імя бягучага карыстальніка, толькі пакуль вы ўвайшлі ў сістэму, а прапушчаную
праверку выконвае пры наступным уваходзе. Пасля пераносу ці пераназвання рэпазіторыя зноў
запусціце `install`.

### Распрацоўка

```bash
npm test          # модульныя тэсты
npm run typecheck
npm run dev       # перазбіраць плагін пры змене файлаў
```

## Заўвагі

- Лакалізацыйныя файлы Steam і ўнутраны `LocalizationManager` — не публічны API. Абнаўленне
  Steam можа зламаць гэты хук, таму плагін правярае яго пры запуску.
- У `translations/` ёсць ангельскія і рускія радкі Valve як зыходны тэкст перакладу. Яны
  застаюцца ўласнасцю Valve і не пакрыты ліцэнзіяй, названай ніжэй.
